01

Application Layer

Provides network services to applications.

HTTP

Transfers web pages and information between browsers and web servers.

HTTPS

Provides secure and encrypted communication over the web.

FTP

Used to transfer files between computers over a network.

SMTP

Used for sending emails across computer networks.

DNS

Converts domain names into IP addresses.

Telnet

Allows remote access to another computer through a network.

02

Transport Layer

Provides communication between devices.

TCP

Provides reliable and ordered delivery of data between devices.

UDP

Provides fast data transmission without establishing a connection.

03

Internet Layer

Handles addressing and routing of data packets.

IP

Provides logical addressing and routes packets between networks.

ICMP

Reports network errors and provides diagnostic information.

IGMP

Manages multicast group membership in IPv4 networks.

04

Network Access Layer

Handles communication over the physical network.

Ethernet

Provides wired network communication between devices.

Wi-Fi

Enables wireless communication between network devices.

PPP

Provides a method for direct communication between two network nodes.
